## Запуск и первые шаги

На Windows откройте `run.bat` в папке игры. Нужна Java 17 или новее; скрипт ищет подходящую установленную версию. Если при прямом запуске JAR появляются числа `61.0` и `52.0`, команда `java` использует Java 8. Используйте `run.bat`; подробности настройки есть в [README](../README.md#сборка-и-запуск).

В главном меню откройте **«Миры»**, создайте мир с именем или загрузите существующий. Можно хранить до пяти миров.

План на первый день:

1. Добудьте дерево: наведитесь на ствол и удерживайте ЛКМ.
2. Разрушайте листья, чтобы получить палки. Шанс выпадения палки — 10%, поэтому она появляется не из каждого блока.
3. Откройте инвентарь клавишей **E**. Сделайте доски из дерева и острую палку из обычной палки.
4. Добудьте камень и уголь. Острая палка ускоряет добычу камня и глубокой породы.
5. Постройте укрытие, сделайте дверь и факелы. Осветите пол внутри и подход к дому.
6. Создайте камнерез для каменных инструментов, затем печь для железных слитков и стекла.
7. Найдите железо в пещерах. Слитки нужны для инструментов, ведра и фонаря.

## Управление

| Действие | Клавиша или кнопка |
| --- | --- |
| Ходить | WASD |
| Смотреть | Мышь |
| Прыгать; всплывать в воде | Space |
| Добывать блок | Удерживать ЛКМ, не уводя прицел |
| Атаковать существо | ЛКМ |
| Поставить предмет из выбранного слота | ПКМ по поверхности |
| Открыть дверь или станок | ПКМ по нему |
| Использовать еду или ведро | ПКМ с предметом в руке |
| Выбрать слот быстрой панели | 1–9, 0 или колесо мыши |
| Режим меток мини-карты | M; ЛКМ поставить, ПКМ удалить ближайшую метку |
| Открыть инвентарь; закрыть инвентарь или станок | E |
| Съесть выбранную еду | ПКМ |
| Пауза | Esc |
| Консоль команд | F3; Enter — выполнить |
| Сохранить и выйти | F10 |

Дальность взаимодействия с блоками — **5 блоков**. Содержимое быстрой панели зависит от вашего инвентаря: положите туда нужный блок или инструмент.

## Инвентарь и крафт

В инвентаре 20 ячеек; первые 10 используются как быстрая панель. Обычные материалы складываются до 64 штук. Инструменты, литейные формы и вёдра занимают отдельные ячейки.

Для переноса нажмите на исходную ячейку, затем на целевую. ЛКМ перемещает стопку, ПКМ переносит один предмет. Так можно раскладывать крафт и загружать станки. Быстрая панель и запас показаны отдельно.

Справа в инвентаре находится сетка крафта **2×2**. Разложите ингредиенты и нажмите на результат. Рецепты могут расходовать несколько предметов из стопки и выдавать несколько предметов; количество результата показано на значке.

### Простые рецепты

Для этих рецептов расположение внутри сетки не важно. Не оставляйте лишних ингредиентов.

| Ингредиенты в отдельных ячейках | Результат за один крафт |
| --- | --- |
| 1 дерево | 4 доски |
| 2 доски | 16 палок |
| 1 палка | 1 острая палка |
| 2 доски + 2 палки, вся сетка | 1 каменная мотыга |
| 3 пшеницы | 1 хлеб |
| 1 золотой слиток | 1 поворачиватель |
| 1 уголь + 1 палка | 1 факел |
| 4 доски, вся сетка | 1 дверь |
| 3 доски, любые три ячейки | 1 блок ступенек |
| 4 камня, вся сетка | 1 печь |
| Навершие топора + палка | Топор соответствующего материала |
| Навершие кирки + палка | Кирка соответствующего материала |
| Навершие лопаты + палка | Лопата соответствующего материала |

### Рецепты станков

Здесь положение ингредиентов важно. Каждая строка таблицы показывает всю сетку 2×2: сначала верхний ряд, затем нижний. На каждую ячейку нужен один предмет.

| Станок | Верхний ряд слева направо | Нижний ряд слева направо |
| --- | --- | --- |
| Камнерез | Камень · Камень | Доска · Доска |


## Ресурсы и инструменты

| Что добывать | Что получите | Для чего нужно |
| --- | --- | --- |
| Ствол дерева | Дерево | Доски, кровать |
| Листья | Иногда палку | Рукояти, факелы, острая палка |
| Обычный камень | Камень | Печь, камнерез, каменные навершия |
| Угольную руду | Уголь | Печи, станки, факелы |
| Железную руду | Предмет «Железо» | Плавка железных слитков |
| Золотую руду (глубина от 8 блоков) | Предмет «Золото» | Золотые слитки, инструменты и поворачиватель |
| Песок | Песок | Стекло в печи |

Железо встречается глубже угля. Исследуйте пещеры с факелами и оставляйте понятный путь назад.

| Инструмент | Основное применение | Прочность |
| --- | --- | --- |
| Острая палка | Камень и глубокая порода | 20 |
| Каменный топор / кирка / лопата | Дерево / порода и руда / земля и песок | 80 |
| Железный или золотой топор / кирка / лопата | Те же материалы, быстрее каменных инструментов | 250 |

Прочность уменьшается при разрушении блоков; при её исчерпании инструмент исчезает. Подбирайте инструмент под материал. Обычный камень и глубокий камень — разные предметы: рецепты с «Камнем» требуют обычный.

## Печь: слитки и стекло

Печь создаётся из **четырёх камней** в сетке 2×2. Откройте её ПКМ: доступны ячейки топлива, сырья и результата. Положите уголь как топливо, а продукт для готовки или плавки — во входную ячейку.

1. Положите уголь в топливную ячейку.
2. Поместите железо, золото или песок во входную ячейку.
3. Плавка начнётся автоматически; нажимать кнопку запуска не нужно.
4. Заберите готовый продукт из выходной ячейки.

| Сырьё | Результат |
| --- | --- |
| 1 железо | 1 железный слиток |
| 1 золото | 1 золотой слиток |
| 1 песок | 1 стекло |
| 1 сырая курятина | 1 жареная курятина |
| 1 баранина | 1 жареная баранина |

**Один уголь обеспечивает до восьми операций печи.** Этот расход относится только к печи. При смене железа на песок сначала заберите слитки с выхода, и наоборот: разные продукты не смешиваются в одной ячейке.

Одна операция занимает около двух секунд; один уголь обеспечивает до восьми операций. Баранину и сырую курятину можно есть сразу. Сырая курятина восстанавливает 2 здоровья, жареная курятина или баранина — 6, обычная баранина — 3. Еда расходуется только если здоровье не полное.

## Камнерез

Камнерез создаёт навершия топора, кирки и лопаты. Откройте его, выберите нужное навершие, загрузите материал и уголь, затем нажмите на изготовление или на пустую выходную ячейку. После изготовления заберите результат.

| Навершие | Расход за одно изделие |
| --- | --- |
| Каменное: топор, кирка или лопата | 1 камень + 1 уголь |
| Железное: топор, кирка или лопата | 5 железных слитков + 1 уголь |
| Золотое: топор, кирка или лопата | 5 золотых слитков + 1 уголь |

Соедините навершие с палкой в обычной сетке 2×2 — получится готовый инструмент. Перед сменой рецепта заберите прежний продукт и замените неподходящее сырьё.

Поворачиватель создаётся из одного золотого слитка. Выберите его в руке и нажмите ПКМ по блоку: направление изменится на 90°. Он работает с дверью, печью, камнерезом, ступеньками и кроватью. Для поворота кровати нужны свободное место и опора. Прочность — 250 успешных поворотов.

## Пример: первая железная кирка

Самый короткий путь через камнерез:

1. Сделайте камнерез и печь по рецептам выше.
2. Переплавьте 5 железа в 5 слитков, загрузив уголь в печь.
3. Выберите в камнерезе железное навершие кирки.
4. Загрузите 5 слитков и 1 уголь, изготовьте и заберите навершие.
5. Соедините его с палкой в инвентаре.

## Вода и ведро

Вода прозрачная и проходимая. В ней движение замедляется; удерживайте **Space**, чтобы всплывать. Под водой видимость уменьшается, а падение в воду смягчается. Вода падает вниз и растекается по опоре; стены останавливают поток. После удаления источника поток постепенно исчезает. Механики утопления нет.

Ведро: три железных слитка в трёх отдельных ячейках крафта 2×2.

- Выберите пустое ведро и нажмите ПКМ по воде — получите ведро воды, а выбранная клетка воды опустеет.
- Выберите ведро воды и нажмите ПКМ по поверхности рядом со свободной клеткой — появится вода, ведро станет пустым.
- Прицел с обычным предметом проходит сквозь воду к твёрдым блокам. Пустое ведро позволяет выбрать саму воду.

## Строительство и выживание

**Дверь** занимает два блока по высоте и требует опоры снизу. Установите её в свободный проём и открывайте ПКМ. Открытая створка пропускает игрока; закрыть её сквозь себя нельзя. Разрушение опоры или любой половины удаляет всю дверь.

**Ступеньки** позволяют подниматься на полблока без прыжка. Направление подъёма задаётся при установке относительно взгляда. Обычные полные блоки преодолеваются прыжком.

**Факел** из палки и угля светит только в руке; установить его нельзя.

**Фонарь**: факел + стекло + железный слиток в трёх ячейках. Ставится ПКМ на твёрдую опору и освещает местность. Старые установленные факелы при загрузке становятся фонарями.

**Кровать**: две шерсти и две доски в четырёх ячейках. Нужны два свободных блока на опоре. ПКМ по кровати пропускает ночь, если поблизости нет зомби. Разрушение любой половины даёт одну кровать.

Стол выплавки, сварочный аппарат и книга рецептов убраны. Старые станки исчезают при загрузке, их обычное содержимое выпадает; удалённые предметы в инвентаре заменяются железными слитками.

**Сутки** длятся 10 минут. Ночью зомби появляются не чаще одного раза в минуту, не более трёх одновременно. Фонари защищают от появления новых зомби в радиусе 12 блоков.

**Здоровье** — максимум 20. Падения с высоты более трёх блоков наносят урон. При получении урона экран кратко краснеет, а задетое существо вспыхивает красным. Овцы дают баранину и шерсть; после удара они убегают. ПКМ с бараниной восстанавливает 3 здоровья. При полном здоровье еда не расходуется.

**Голод** — шкала до 20 рядом со здоровьем. Она теряет единицу примерно каждые 35 секунд игры. При нуле игрок получает урон каждые 5 секунд. ПКМ с едой восстанавливает голод и, если нужно, здоровье. Хлеб делается из трёх пшениц; курятину и баранину можно жарить в печи.

**Фермерство**: ломайте листья, чтобы получить семена пшеницы; шанс небольшой. Сделайте каменную мотыгу из двух досок и двух палок. Наведитесь на дёрн и нажмите ПКМ мотыгой, чтобы вспахать землю; ПКМ с семенами по грядке посадит пшеницу. Она проходит четыре стадии роста примерно за полторы минуты игры. Удерживайте ЛКМ на зрелом колосе: получите пшеницу и семена. Посевы и голод сохраняются вместе с миром.

**Смерть** возвращает игрока с полным здоровьем, но предметы выпадают, если не включено сохранение инвентаря. Для спокойного строительства можно включить его командой ниже.

## Креатив

**F3 → `gamemode 1` → Enter** включает креатив. **E** открывает каталог всех доступных предметов: нажмите слот панели, затем нужный предмет; стрелки листают страницы. Пробел поднимает игрока, левый Shift опускает, WASD перемещает. Блоки и прочность инструментов не расходуются, блоки разрушаются сразу, урон и голод отключены.

**`gamemode 0`** возвращает выживание. Режим сохраняется вместе с миром, предметы инвентаря при переключении остаются.

## Сохранения и команды

Игра автоматически сохраняется каждые 30 секунд игры, при паузе и штатном выходе. В меню паузы есть ручное сохранение. Миры лежат в папке `saves`; для резервной копии закройте игру и скопируйте эту папку.

В настройках можно менять дальность прорисовки, чувствительность мыши и угол обзора. Если игра тормозит, начните с уменьшения дальности.

Консоль открывается **F3**, команда выполняется клавишей **Enter**. Следующие команды удобны для знакомства с механиками в отдельном мире:

| Команда | Действие |
| --- | --- |
| `time set day` | Установить день |
| `time set night` | Установить ночь |
| `keepInventory true` | Сохранять инвентарь после смерти |
| `keepInventory false` | Снова включить выпадение инвентаря |
| `give furnace 1` | Выдать печь |
| `give iron 12` | Выдать сырое железо |
| `give iron_ingot 12` | Выдать железные слитки |
| `give coal 16` | Выдать уголь |
| `give stick 4` | Выдать палки |
| `tp river` | Переместиться к ближайшей найденной воде |


## Если что-то не получается

| Проблема | Что проверить |
| --- | --- |
| Нет результата в крафте | Нужное число отдельных ячеек, отсутствие лишних предметов, различие дерева и досок |
| Печь не плавит | Есть ли уголь или остаток топлива; на входе железо либо песок; выход не заполнен другим продуктом |
| Нажатие на выход только забрало предмет | Для следующего изделия снова нажмите на уже пустой выход |
| Нельзя забрать результат | Освободите место в инвентаре; форме, инструменту и ведру нужна отдельная ячейка |
| Не хватает палок | Разрушайте листья или скрафтите 16 палок из двух досок |
